# MEDIZ - Backend

**MEDIZ** is a web application designed to streamline hospital administration by offering a centralized backend system built with Node.js and MongoDB. This repository contains all the APIs and business logic for managing patient records, staff data, pharmacy stock, doctor schedules, illness prediction, and automated notifications.

## 🚀 Features

- 🏥 Patient Management (CRUD)
- 👨‍⚕️ Staff and Doctor Scheduling
- 💊 Pharmacy Inventory Management
- 🧠 AI-Powered Illness Prediction (Python integration or external API)
- 📧 Automated Email Notifications
- 📦 Real-time Stock Updates
- 🛡️ RESTful API with Express.js

## 🧰 Tech Stack

- **Node.js**
- **Express.js**
- **MongoDB + Mongoose**
- **Python (for AI/ML services integration)**
- **Dotenv** for environment variables
- **Nodemailer** for email notifications
